The raw trace records normalized CPU and memory demand. It does not contain
lengthMI or absolute RAM, so prepare_google_trace.py maps normalized fields to
the simulator schema:

  - lengthMI = max(1, round(NrmlTaskCores * 1_000_000))
  - pes      = max(1, min(4, ceil(NrmlTaskCores * 32)))
  - ramMB    = max(1024, round(NrmlTaskMem * 64 * 1024))
  - priority = JobType

tasks.csv is therefore a trace-derived dataset; lengthMI and ramMB are proxies
because the Version 1 trace does not expose absolute execution time or memory.
